# Smallnext Android 리뷰 규칙

- 진행 상태·입력 초안·완료 기록·보류·목표 중단·목표 삭제를 같은 도메인 의미로 사용한다. 화면·저장·복구·취소·늦은 응답의 리비전 검사를 확인한다.
- 저장 데이터와 스키마 변경의 기존 데이터 보존·실패·복구를 확인한다. 플래그 OFF의 기존 흐름과 ON의 정상·실패 흐름을 확인한다.
- 접근성·글자 크기·모션 감소·앱 수명 주기와 네트워크 오류의 회귀를 확인한다. 에뮬레이터 결과를 실제 사용자 기기 검증으로 보고하지 않는다.
- AI·진단 전송의 동의·인증·비밀정보 경계를 유지한다. 앱에 서버 비밀정보를 포함하지 않는다.

기준 자료: `CONTEXT.md`, `docs/DEVELOPMENT.md`, `docs/SERVER_AI.md`의 앱 계약, 관련 Issue의 확정 답.
