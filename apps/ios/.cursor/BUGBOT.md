# Smallnext iOS 리뷰 규칙

- 진행 상태·입력 초안·완료 기록·보류·목표 중단·목표 삭제를 같은 도메인 의미로 사용한다. 화면 전환과 저장·복구·취소·늦은 응답의 리비전 검사를 확인한다.
- 플래그 OFF의 기존 흐름과 ON의 정상·실패 흐름을 확인한다. 사용자 화면에는 필요한 정보만 표시한다.
- VoiceOver·글자 크기·모션 감소와 실제 사용자 흐름의 회귀를 확인한다. 단위 테스트·시뮬레이터·archive를 서명된 실기기·접근성 검증으로 보고하지 않는다.
- 개발용 AI·Crashlytics의 동의·전송·비밀정보 경계를 유지한다. 기기 검증 보류를 소스 변경이나 CI 성공으로 해제하지 않는다.

기준 자료: `CONTEXT.md`, `docs/DEVELOPMENT.md`, `docs/CRASHLYTICS.md`, 관련 Issue의 확정 답. 실기기 검증은 Issue #61의 보류 조건을 확인한다.
