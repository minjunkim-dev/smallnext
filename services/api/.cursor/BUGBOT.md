# Smallnext API 리뷰 규칙

- Rust의 공개 API와 저장 계약, OpenAPI·앱 호출자 호환성을 확인한다. DB 변경은 기존 데이터·transaction·경합·롤백·삭제 범위에 대한 근거를 요구한다.
- 사용자용 서버 AI는 기본 OFF다. OFF의 기존 동작과 ON의 인증·권한·철회·허용 사용자·입력 한도를 확인한다. 인증 조회 실패에서 AI를 호출하지 않는다.
- 생성·검사·예산 예약·정산·취소·시간 제한의 계약을 보존한다. 자동 재시도·재생성·모델 대체로 호출이나 비용을 늘리지 않는다. 미확인 사용량을 임의로 환급하지 않는다.
- 실패·거부·불확실·취소 후보를 적용하지 않는다. 늦은 응답이 현재 리비전을 덮어쓰지 않도록 확인한다.
- UID·목표·입력·응답·인증정보 원문의 보관·로그·외부 전송을 확인한다. 운영 연결·단가·IAM·보관·삭제·백업은 소스와 mock만으로 검증했다고 보고하지 않는다.

기준 자료: `docs/SERVER_AI.md`, `contracts/openapi.json`, 변경에 관련된 Issue의 확정 답과 요청별 생성·검사 계약. 연구 문서 전체를 상시 규칙으로 펼치지 않는다.
