# 현재 행동 화면 시제품

질문: 같은 현재 행동을 어떤 화면과 모션으로 보여주면 시작하기 쉬운가?

[현재 행동과 분할·완료 모션은 어떻게 보여야 하는가?](https://github.com/minjunkim-dev/smallnext/issues/8)의 검토 자료입니다.
임시 브랜치에서만 보관합니다. 제품 구현과 AI 품질의 증거로 사용하지 않습니다.
현재 main에는 앱 화면이나 웹 라우터가 없습니다. 제품 문서 옆에 독립된 임시 페이지를 둡니다.

## 실행

```sh
python3 docs/prototypes/current-action/run.py
```

브라우저에서 <http://127.0.0.1:8767/?variant=A>를 엽니다.
Python 표준 라이브러리만 사용합니다. 서버는 loopback 주소에만 연결합니다.
`Ctrl+C`로 서버를 종료합니다.

## 비교

1. A: 종이 카드. 분할할 때 두 부분의 관계를 짧게 보여줍니다.
2. B: 큰 문장. 카드 없이 내용만 교체합니다.
3. C: 아래쪽 패널. 설명과 버튼을 손이 닿는 위치에 모읍니다.

아래 전환 막대와 좌우 방향키로 화면을 바꿉니다. 선택은 `?variant=A`, `B`, `C`에 남습니다.
입력 칸에서 방향키를 누르면 화면을 바꾸지 않습니다.
시제품 서버가 제공하는 설정이 있을 때만 검토 도구를 표시합니다. 정적 파일에서는 숨깁니다.

## 확인할 흐름

‘더 작게’ → 역할 하나 표시 → ‘완료’ → 다음 행동을 눌러 봅니다.
두 번째 ‘더 작게’에서는 막힌 이유 하나를 선택합니다.
‘목표 보기’는 별도 화면입니다. 기본 실행 화면에는 최종 목표와 전체 할 일 목록을 표시하지 않습니다.
보조 메뉴의 ‘되돌리기’는 분할 직전으로 돌아갑니다. 완료 취소로 사용하지 않습니다.
‘나중에’는 완료 없이 준비된 다른 행동으로 이동합니다.

검토 도구에서 일반·모션 감소·모션 없음과 지연·실패·다음 행동 없음을 비교합니다.
기본은 OS 모션 감소 설정을 반영합니다. ‘일반 모션 (검토용)’은 비교할 때만 직접 선택합니다.
기본 모션의 시간 값은 시제품 비교값입니다. 확정 사양이나 공식 기준이 아닙니다.
모션은 결과 적용 후 시작합니다. 서버 지연은 별도로 표시합니다.
중복 탭으로 다음 행동까지 완료하지 않도록 짧은 입력 잠금을 사용합니다.

## 자료와 한계

사용자가 확정한 이직 준비 사례를 바탕으로 사람이 쓴 예시입니다.
개인 원고, 연락처, 회사 문서와 원본 자료는 포함하지 않습니다.
예시 편집 내용, 완료·보류 기록은 메모리에만 남습니다. 새로 고침하면 초기화됩니다.
실제 자료 파일에 표시하거나 문장을 저장한 증거가 아닙니다.
최종 목표의 실제 진행률을 계산하지 않습니다.
실제 AI 요청, 인증, 영구 저장, 동기화, 네이티브 햅틱·소리와 기기 성능은 검토 범위 밖입니다.
접근성 속성과 모션 감소 경로를 제공하지만 전체 접근성 적합성을 선언하지 않습니다.
화면과 모션의 확정 답은 사용자의 반응 후 결정 Issue에 기록합니다.
