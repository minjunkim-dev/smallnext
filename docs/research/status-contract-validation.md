# 상태별 생성·검사 계약 회귀

[#94](https://github.com/minjunkim-dev/smallnext/issues/94)의 공통 계약 수정과 Claude Code 구독 OAuth 재검증 기록입니다.
이전 검증은 [생성·검사 계약과 분리 평가](generator-checker-validation.md)를 참조합니다.

## 변경

생성 역할과 검사 역할에 같은 [공통 계약](../../services/api/src/development_ai/contract.md)을 전달합니다.
개발 CLI와 사용자용 API가 같은 조합 함수를 사용합니다.
상태를 먼저 결정합니다. 보류 행동은 실제 작업·대상·결과로 비교합니다.
준비된 목록에 같은 행동이 있어도 보류를 우선합니다.
유용한 축소가 없고 첫 실제 막힘을 모르면 need_info를 사용합니다.
질문·목표 초안·보류 유지에는 각 상태에 맞는 다섯 기준을 적용합니다.
행동과 minimum의 실제 진행·제약·축소·보존 기준은 유지합니다.

모델·effort·timeout·예산·schema·피처 플래그는 변경하지 않습니다.
영구 개발 공급자는 Codex CLI입니다. Claude Code 구독은 임시 QA 어댑터에서만 사용합니다.

## 고정 평가

[상태 회귀 입력](fixtures/status-contract-checks.json)에 정상/실패 쌍 다섯 개와 시뮬레이터의 원래 실패 입력을 기록합니다.
원래 입력의 오래된 문서 상태도 수정하지 않습니다.
참조는 AI가 작성한 합성 기준입니다. 사람의 전수 품질 승인이나 일반화 성능이 아닙니다.
기존 검사 입력 21개와 새 검사 입력 10개를 각각 1회 실행합니다.
생성 입력 12개를 실행합니다. 두 과거 실패 입력을 각각 1회 추가 반복합니다.
최대 CLI 실행은 59개입니다. 병렬 실행 수는 2입니다. 생성·검사 전체 제한은 120초입니다.
참조·기대 판정·사례 ID를 모델에 전달하지 않습니다.
실제 호출 전에 입력·프롬프트·schema·바이너리를 고정합니다.
출력 제한에 도달하면 임시 어댑터는 첫 max_tokens에서 종료합니다. 추가 복구 요청을 허용하지 않습니다.
출력 토큰 제한이나 추론 강도는 별도로 낮추지 않습니다.

## 결과

Rust 일반 테스트 30개와 격리 PostgreSQL 검사 11개를 통과했습니다.
Python 테스트 107개와 repository/workflow/clippy/OpenAPI/diff 검사를 통과했습니다.
공통 계약 누락 회귀는 기존 코드에서 실패했고 수정 후 통과했습니다.
API HTTP 통합 검사는 CLI와 같은 계약, 요청별 schema, 모델과 xhigh 전달을 확인합니다.
모의 제공사 테스트는 실제 모델 품질의 근거로 계산하지 않습니다.

Claude Code의 로그인 상태는 loggedIn=true, authMethod=claude.ai, subscriptionType=max입니다.
새 키나 토큰 추출 없이 기존 구독 OAuth로 실행했습니다.
완료 응답 59개는 실제 modelUsage=claude-haiku-5-5입니다. effort=xhigh를 유지했습니다.

| --- | --- | --- | --- |
| 독립 검사 회귀 | 31/31 참조 일치 | 13.572초 | 27.744초 |

검사 회귀는 유효 후보 15개를 수용하고 의미 위반 후보 16개를 거절했습니다.
생성 결과 원문도 참조와 비교했습니다. 보류 재제안·동일 작업 minimum·범위 누락은 없습니다.
정상 수량 축소, 다른 준비된 대안, 알려진 막힘의 도움, 명시적 반복 실패 질문을 보존했습니다.
참조 status와 구조 통과만으로 의미 품질 전체를 승인하지 않습니다.

이전 동일 보류 입력은 32.617–39.553초였습니다. 이번 결과는 17.552–18.882초입니다.
이전 보고서 입력은 110.404초의 거절 또는 전체 120초 시간 초과였습니다.
이번에는 66.312초와 67.853초에 첫 실제 막힘 질문을 수용했습니다.
입력과 모델·effort는 유지했습니다. 공통 계약을 바꾸어 의미 실패와 시간 초과 재현을 없앴습니다.
다만 보고서 응답은 여전히 약 1분입니다. 응답 시간이 충분히 짧다고 승인하지 않습니다.
보고서 생성 API 시간은 20.447초·27.768초입니다. 검사 API 시간은 43.616초·37.945초입니다.
남은 지연은 검사 단계가 가장 큽니다. 이 측정만으로 모델만의 문제라고 단정하지 않습니다.

CLI 실행은 59개이고 제공사 message_start는 61개입니다.
CLI 내부 구조화 처리 때문에 이 두 수를 동일하게 계산하지 않습니다.
max_tokens 이벤트는 0개입니다. 외부 하네스와 Rust는 재시도하지 않았습니다.
추적한 CLI 자식 프로세스 59개는 모두 종료했습니다.
완료 출력은 185,307토큰이고 추론 출력은 142,451토큰입니다.
CLI의 토큰·시간은 운영 API의 청구·지연 증거가 아닙니다.
임시 어댑터의 추가 요청 차단을 영구 개발 공급자에 구현했다고 보고하지 않습니다.

고정 입력 SHA-256은 f41c4acc92c73d342c2c585bac40ab85451404fd888c3009ab307614fd7c680f입니다.
조합한 생성 프롬프트 SHA-256은 9e577cadd4d90aa85d6e14c580b278b5843f944c2bb8f3d03d09bdaee15a5eec입니다.
조합한 검사 프롬프트 SHA-256은 0c31525b0febb63366ee455a0085296c283dbaae55b2a0675e0a5254b4d08160입니다.
결과를 본 뒤 프롬프트나 참조를 수정하지 않았습니다.
합성 원문·결과·manifest와 하네스는 로컬 validation94에 보존합니다.
원문 보관 기한은 2026-11-08입니다. 자동 삭제는 없습니다.

iOS 화면과 실기기는 이번에 다시 검증하지 않았습니다. 원래 시뮬레이터 입력을 Rust 경로에서 재생했습니다.
별도 PostgreSQL 컨테이너는 검사 후 삭제했습니다. 피처 플래그 기본값은 OFF입니다.
일반화 품질, 운영 API 인증·청구, 실제 화면 지연과 모델 출시 적합성은 미확인입니다.
