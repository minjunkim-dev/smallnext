# 미결정 항목

이 문서는 아직 결정하지 않은 질문을 기록합니다.
검토안은 확정한 결정과 구분합니다. 실제 결정의 근거는 해당 Issue에 기록합니다.

## 첫 검토 질문

1. 첫 시제품은 어떤 사용자 상황을 검증해야 하는가?
2. '더 작게'의 원인을 어떤 방식으로 입력받아야 하는가?
3. 분할 전후 카드에는 어떤 정보가 필요하며 어떻게 전환해야 하는가?
4. 첫 배포 플랫폼과 앱 기술 스택은 무엇이어야 하는가?
5. 목표 분할 품질을 어떤 예시와 기준으로 평가해야 하는가?

## AI 연결 검토안

서버 AI API를 기본으로 시작하는 방안을 검토했습니다.
로컬 모델과 사용자 에이전트 연결은 추가 선택지입니다.
제공자, 모델, 인증 방식, 비용 한도, 개인정보 처리 방식은 아직 결정하지 않았습니다.
기존 에이전트 구독과 API 사용 권한은 같은 것으로 가정하지 않습니다.

AI 연결부를 교체해도 목표와 완료 이력의 의미는 유지되어야 합니다.
AI는 분할안을 제안하고 앱은 완료 상태와 수정 이력을 관리하는 방안을 검토합니다.

## 결정 기록 형식

Issue에는 질문, 선택한 답, 이유, 검증 근거, 재검토 조건을 기록합니다.
문서에 같은 결정의 상세 내용을 반복하지 않습니다.
