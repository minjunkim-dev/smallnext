# 미결정 항목

이 문서는 아직 결정하지 않은 질문을 기록합니다.
검토안은 확정한 결정과 구분합니다. 실제 결정의 근거는 해당 Issue에 기록합니다.

## 현재 결정 지도

[첫 버전의 개발 사양 지도 #2](https://github.com/minjunkim-dev/smallnext/issues/2)에서 열린 질문과 의존 관계를 확인합니다.
대표 목표, 입력·카드, 재분할, 품질 기준의 확정 답은 각 Issue의 해결 댓글에 있습니다.
이 문서에 결정 상세를 복제하지 않습니다. 과거 질문 목록을 현재 미결정 목록으로 사용하지 않습니다.
앱 초기 셋업의 검증과 제품 기능의 확정·구현을 구분합니다.

## 초기 셋업과 제품 결정

앱·API·모노레포의 초기 셋업 범위와 검증은 [Issue #13](https://github.com/minjunkim-dev/smallnext/issues/13)에 연결합니다.
구현 구성과 실행 방법은 [개발 환경](DEVELOPMENT.md), 검증 범위는 [셋업 검증](SETUP_VALIDATION.md)에 기록합니다.
첫 제품의 플랫폼과 배포 조건은 [Issue #11](https://github.com/minjunkim-dev/smallnext/issues/11)의 확정 답을 따릅니다.
초기 셋업의 병합만으로 제품 결정 Issue를 종료하지 않습니다.

## AI 연결 검토와 결정

연결 방식, 실패 시 동작, 비용과 데이터 처리의 확정 답은 [Issue #10](https://github.com/minjunkim-dev/smallnext/issues/10)을 기준으로 확인합니다.
서버 AI의 공급자와 모델 선택은 [Issue #17](https://github.com/minjunkim-dev/smallnext/issues/17)에서 진행합니다.
실제 AI 연결과 품질 검증은 결정 기록과 별도로 확인합니다.

## 결정 기록 형식

Issue에는 질문, 선택한 답, 이유, 검증 근거, 재검토 조건을 기록합니다.
문서에 같은 결정의 상세 내용을 반복하지 않습니다.
