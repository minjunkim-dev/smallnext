# Smallnext 검증 스크립트 리뷰 규칙

- shell에 외부 값을 직접 삽입하지 않는다. 안전한 argv·env와 최소 권한을 사용한다. 비밀정보를 가진 환경·파일·로그를 모델이나 PR 코드에 전달하지 않는다.
- 오류·timeout·취소·하위 프로세스 회수·임시 파일 소유권과 정리를 보존한다. 삭제·덮어쓰기·경로 탈출·큰 출력·부분 결과의 실패 처리를 확인한다.
- 정상·실패 경로를 호출자의 interface로 검사한다. 상수 재단언·소스 문자열 순서·항상 성공하는 mock을 동작 검증으로 보고하지 않는다. 확인한 버그의 기존 재현 검사를 약화하지 않는다.
- GitHub 수집·집계·게시의 pagination·최신 attempt·정확한 SHA·권한·최종 상태 대조를 유지한다. 실패를 성공이나 미설치·미연결의 증거로 바꾸지 않는다.
- 모의 AI 응답·통계·archive 검사를 실제 유료 API·품질·청구·기기·운영 검증으로 보고하지 않는다. 승인되지 않은 실제 AI·배포·계정 변경을 실행하지 않는다.

기준 자료: `docs/coding-standards.md`, `docs/CI.md`, `docs/DRAFT_RELEASE.md`, 관련 Issue의 확정 완료 조건.
